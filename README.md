# PigThings

Minecraft 辅助模组，提供飞行、挖掘、传送等实用能力，以及小猪主题装备与道具。

## 支持版本

| Minecraft | 加载器 | 模组版本 | 必需依赖 | 工程目录 |
| --- | --- | --- | --- | --- |
| 1.12.2 | Forge | 1.7.12 | Baubles | [1.12.2](1.12.2/) |
| 1.20.1 | Forge | 1.6.5 | Curios | [1.20.1](1.20.1/) |
| 1.21.1 | NeoForge | 1.6.5-neoforge | Curios | [1.21.1](1.21.1/) |

请选择与 Minecraft 版本和加载器匹配的模组及依赖。

## 主要物品

| 物品 | 功能 |
| --- | --- |
| 全知“猪头”轻型头盔 | 创造飞行、速度调节、无惯性、夜视、饱和、磁铁等，佩戴后按 G 设置。 |
| 拱开虚空指环 | 提供主要辅助能力，设置独立保存；与头盔同时装备时头盔优先。 |
| 障碍破坏者 | 高速挖掘、无限耐久、右键单格破坏，支持精准采集。 |
| 矿脉挖掘镐 | 连锁挖掘，仅 1.20.1 提供。 |
| 拔刀吧！胡萝卜 | 胡萝卜唐刀，近战一击必杀。 |
| 卡墙猪灵的遗骨 | 右键获得 30 秒幽灵化，可飞行、穿墙并免疫伤害，冷却 10 秒；仅 1.12.2、1.20.1 提供。 |
| 猪咪锭 | 小猪主题材料。 |

## 版本差异

- **1.12.2、1.20.1**：头盔支持液体清晰视野；唐刀支持 Shift + 右键沿视线传送，最远 16 格。
- **Ender IO 兼容**：1.12.2、1.20.1 可选安装对应版本的 Ender IO，唐刀可使用旅行权杖闪现与旅行锚传送，无需充能。
- **幽灵化**：攻击、挖掘或其他交互会结束效果，结束时在原地恢复碰撞与伤害。

## 文件目录

```text
1.12.2/          Forge 1.12.2 工程
1.20.1/          Forge 1.20.1 工程
1.21.1/          NeoForge 1.21.1 工程
assets/         共用模型原稿与参考图
docs/           项目文档与演示素材
dist/           成品 JAR，按 Minecraft 版本分类
```

各版本的源码、游戏资源与本地依赖分别位于对应工程的 `src/`、`src/main/resources/` 和 `libs/` 中。
